# CodeGrid '26 — Hackathon Registration Website

A responsive, single-page website created for the **Software Development Team Recruitment Task (Task 2)** of the Data Science Club. The project is a frontend-only registration website for a fictional 24-hour hackathon called **CodeGrid '26**.

**Live Demo:** https://stupendous-syrniki-4a0de4.netlify.app/ 


---

## About the Project

The goal of this project was to design a modern and interactive hackathon registration website using only frontend technologies. The website includes all the required sections mentioned in the task and a few additional features to improve the overall user experience.

Everything is built using **HTML, CSS, and JavaScript** without any frameworks or external libraries.

---

## Features

### Required Features

- Responsive Hero section with a live countdown timer
- About section describing the hackathon tracks
- Interactive event schedule displayed as a timeline
- Prize section highlighting different reward categories
- Sponsors section with placeholder sponsor logos
- Registration form with client-side validation

### Additional Features

- Dark and Light mode with saved user preference
- Live countdown timer for the event date
- Smooth scroll animations
- Animated particle background on the hero section
- Interactive hover effects on cards
- Animated statistics counter
- Simple image gallery
- Registration success popup without refreshing the page
- Fully responsive layout for desktop, tablet, and mobile devices
- Footer with social media links
- Form validation using JavaScript (email, phone number, required fields)

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Canvas API (for particle animation)
- Intersection Observer API
- LocalStorage (for theme persistence)
- Google Fonts

## Running the Project

Clone the repository:

```bash
git clone <your-repository-link>
```

Go to the project folder:

```bash
cd hackathon-site
```

Open **index.html** in your browser.

You can also run a local server:

```bash
python3 -m http.server 8000
```

Then open:

```
http://localhost:8000
```
